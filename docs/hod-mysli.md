# Simurg тестовое — оригинальная концепция

**Референс по стилю:** simurg.life/mudroe_vospitanie (палитра, типографика, настроение)  
**Не копируем:** ассеты, Zero Block координаты, иллюстрации с их CDN

## Подход

- **Стиль бренда:** Involve, `#393B6F`, `#FFF2C8`, peach-gradient CTA, `#DC5B33` акценты
- **Своё:** grid-layout, CSS-декор (звёзды, glow, wave), авторский logo-mark.svg
- **Иллюстрации:** сгенерированы под задачу (`hero-original.png`, `story-original.png`)

## ЭКРАН 1 — Promo

- Split grid: текст слева, иллюстрация в organic frame справа
- Badge «15–22 июня» pill
- Заголовок 52px cream, CTA с тенью
- Фон: gradient purple + blur-orbs + CSS stars

## ЭКРАН 2 — Story

- Header: mark + заголовок по центру
- Grid: иллюстрация слева, тексты справа
- Pull-quote для акцентного абзаца
- Closing terracotta по центру
